# Project X

First wireframe section of Project X — a mobile-first, minimalist/neumorphic cinematic web experience.

## Structure

- Header
- Welcome video
- Project introduction
- Functional music player + CSS vinyl
- Photo section
- Current footer

## Replaceable assets

Add these files under `/assets/` when ready:

- `welcome.mp4` — intro video
- `welcome-poster.jpg` — optional video poster
- `music.mp3` — music player audio
- `ayush-photo.jpg` — photo placeholder replacement

No copyrighted music is bundled.

Additional website sections can be appended after the current footer without restructuring the existing components.
